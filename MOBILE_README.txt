AURA V3 MOBILE QUICK START

1. Unzip AURA_V3.
2. On PC, run a local web server.
3. For development, open http://localhost:8080.
4. For phone testing on the same Wi-Fi, expose the server to the LAN.
5. For installable phone PWA behavior, deploy to HTTPS.
6. Open AURA and tap Add music.
7. Import your audio files.
8. Use the browser/device Add to Home Screen / Install command.

The same codebase adapts automatically to phone and desktop layouts.
